## Runtime and integrity

Local-run checks endpoint-reported model ID, can verify a local GGUF file hash, disables proxies/redirects and performs at most one generation attempt per accepted pair. Immutable intent records precede requests. Failed transport stops further calls. Interrupted attempts remain unsettled, with no retry. A blocked run still creates a useful source-reading page. Read-only loopback serving is optional and contains no model action.

Evidence validation rejects incomplete/reordered block coverage, duplicate pairs, forged language prefixes, model-authored human review states and invalid evidence locations. Model request accounting is derived from saved attempts; source facts remain separate from model candidates. B2 prompt/parser/tokenizer source files are unchanged. Adapter version is v2; older analysis evidence remains replayable with its pinned original source revision, not silently rewritten.
