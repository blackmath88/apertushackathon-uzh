Method & evaluation

This workspace shows possible semantic differences, not an automatic verdict. Check the original passages and their context before confirming a difference. Missing content needs a check of the full source.

The research benchmark measures token-level agreement with human annotations. This review workspace is a separate application; no benchmark accuracy is claimed here. Analysis is prepared by the local runner; this page does not start inference or monitor websites.

Reviews are saved in this browser when storage is available. Reviewer names are self-declared. The JSON export remains a draft for validation with the project’s review command.
